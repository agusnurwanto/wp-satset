### Progress Intervensi AIDS
- Plugin membuat halaman publik **Progress Intervensi AIDS** dengan shortcode `[progress_intervensi_aids]` dan menautkannya pada daftar **HALAMAN TERKAIT** serta pengaturan **Data AIDS**.
- Halaman merangkum data per tahun anggaran: capaian T&T layanan, pendampingan komunitas, distribusi UPK, kelompok umur, indikator populasi LSL, dan tren tanggal pendaftaran.
- Data HIV sangat sensitif. Halaman hanya menampilkan agregat; rincian dengan kelompok berjumlah 1–4 disamarkan dan rincian terkait juga disembunyikan untuk mencegah penghitungan balik. Jangan menambahkan identitas atau tabel pasien ke halaman publik.
- Skema saat ini tidak mencakup catatan pengambilan ARV berkala atau viral load, sehingga retensi/kepatuhan ARV dan supresi virus tidak dihitung.

### Progress Intervensi Malaria
- Plugin membuat halaman publik **Progress Intervensi Malaria** dengan shortcode `[progress_intervensi_malaria]`, serta menautkannya pada daftar **HALAMAN TERKAIT** dan pengaturan **Data Malaria**.
- Halaman merangkum tindak lanjut, hasil akhir, dan status pengobatan secara agregat per tahun anggaran dan desa. Tabel menggunakan paginasi, diurutkan berdasarkan total kasus, dan menyediakan aksi untuk melihat desa di peta. Prompt analisis AI memakai token untuk nama/alamat wilayah dan kategori status baku (bukan teks status bebas). Jika total kasus lebih dari 100, lokasi dibatasi maksimal 50 dan kelompok kecil berjumlah 1–4 serta total yang berisiko mengungkap kelompok kecil disamarkan; jika totalnya 100 atau kurang, semua lokasi dan hitungan status disertakan. Identitas pasien tidak dikirim.
